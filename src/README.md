# Source modules

Reusable project functions can be organised here rather than duplicated across notebooks.

Suggested modules:

- `preprocessing.py` — data loading, cleaning and validation helpers
- `feature_engineering.py` — PEMFC-informed pressure, temperature and dew-point descriptors
- `models.py` — model construction and evaluation helpers
- `eda.py` — reusable exploratory-analysis functions
- `utils.py` — shared utilities, paths and reproducibility helpers

The dissertation analysis was developed primarily through Jupyter notebooks; this directory is intended for reusable functions extracted from that workflow.
